```
I need a set of sticker images for a Korean-themed cafe photobooth. They must look like one set, so hold this style exactly for every image I ask for in this conversation:

Medium: flat vector sticker illustration, thick uniform outline, minimal interior detail.
Line: bold even-weight contour line, roughly 6% of the icon's width, no line tapering.
Shading: flat fills only, no gradients, no drop shadows, no ambient occlusion.
Color: use ONLY these colors: deep forest green #123B26, warm cream #F7F1E3, teak brown #8A5A34, butter yellow #E8B84B, and at most one accent from soft red #D94F4F / dusty pink #F2A8C0 / sky blue #4FA3C4.
Composition: single centered subject, filling 85% of a square frame, nothing cropped by the edge.
Background: fully transparent background, no backdrop, no ground shadow, no frame, no border.
Mood: warm, cozy, retro Korean cafe stationery; charming but restrained; hand-drawn warmth with geometric discipline.
Constraints: no text, no letters, no numbers, no logos, no watermark, no signature. The result must stay legible when scaled down to 44 pixels tall.
Avoid: photorealism, 3D render, glossy plastic, gradients, drop shadow, busy detail, text, watermark, white background, checkered background, multiple subjects, cropped subject, harsh neon colors, anime shading.
Output: 1024x1024 PNG with alpha channel. Square with real transparency. If the source cannot emit alpha, generate on a solid #FF00FF magenta field so the key color can be removed cleanly.

Reply "ready" and wait. Then I will name one subject at a time. For each, generate exactly one image in the style above and nothing else.
```
